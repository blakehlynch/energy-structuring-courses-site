How to use this site

  • Work through modules in order. Each has objectives, a lesson, worked examples whose numbers are checked by code, interactive tools, a quiz and flashcards.
  • Progress, quiz scores and known flashcards are saved in this browser only (localStorage). Using a different browser or clearing site data starts fresh.
  • Amber Dated boxes mark material that has probably changed since the book was written, with a current source to check.
  • Violet ALM analogy boxes connect a concept to asset-liability management.
  • The library page lists every book, its extraction status, and which courses use it.
