Prerequisites

An event tree for project value

A binomial lattice discretises the path of the underlying, here the present value of the project without flexibility. In a multiplicative tree, value moves up by \(u\) or down by \(d = 1/u\) each step, the tree recombines, and the end values approach a lognormal distribution. If value can go negative, an additive tree, which tends to a normal distribution, may fit better. Copeland & Antikarov ch.5 (pp.122–124) Projects pay out cash, like a dividend. To keep the tree recombining, payouts are taken as a fixed proportion of value in a multiplicative tree, or a fixed amount in an additive one. Copeland & Antikarov ch.5 (pp.124–125) With volatility \(\sigma\), step \(\Delta t\), risk-free rate \(r\) and payout rate \(\delta\):

\[ u = e^{\sigma\sqrt{\Delta t}},\quad d = 1/u,\quad p = \frac{e^{(r-\delta)\Delta t} - d}{u - d} \]

σ = 30%, Δt = 1, r = 5%, δ = 4%: u = 1.3499, d = 0.7408, risk-neutral p = 0.4421 check: a 500-step tree prices a 1-year at-the-money call (S = K = 100, σ = 30%, r = 5%) at $14.2254 versus Black–Scholes $14.2312

Always test a lattice against a closed-form case before trusting it on a problem that has none. Synthesis

Options on an operating project

Hull lists the embedded options most projects carry. Abandonment is an American put on project value, struck at the liquidation value. Expansion is an American call on extra capacity, struck at the cost of expanding. Contraction is a put on part of the project, struck at the savings. Options to defer, extend life, or switch inputs and outputs also appear. Hull ch.36 (p.784) On a lattice each is a comparison at every node: keep operating (collect the payout and the discounted continuation value), or exercise whichever alternative is worth more. Work backward from the end. Copeland & Antikarov ch.5 Synthesis

Worked example 2 · abandon, expand, contract, separately and togetherChecked by code

An operating asset's value without flexibility is $200, with 30% volatility, r = 5%, a 4% annual payout and a 5-year horizon (250 steps). Options: abandon for $150 salvage, expand by 30% for $50, or contract by 25% to save $40.

abandon alone: $19.19; expand alone: $18.40; contract alone: $5.78 → sum $43.36 all three together: $37.39

Option values don't add. Abandonment and contraction both pay off in the low states, and exercising one removes the other, so the combination is worth less than the sum. Expansion pays in the high states and interacts less. Value the package of options together on one tree. Copeland & Antikarov ch.6 Synthesis

Real-options lattice

Value of flexibility on an operating project

Base value $200, r = 5%, payout 4%, 5 years, 250 steps. Expansion costs $50, and contraction gives up 25% of value. Push the salvage value near $200 and abandonment dominates the package.

An undeveloped project: deferral

Before investment, the project is an American call on its value, struck at the investment cost. While you wait you don't receive the project's payouts, which is what makes early exercise worthwhile. Dixit & Pindyck ch.5 §1 Synthesis

Worked example 3 · a five-year development windowChecked by code

The project would be worth $200 today and costs $210 to build. Volatility 30%, r = 5%, payout 4%, and the licence runs 5 years.

NPV today = −$10 (don't build now); value of the licence = $45.12

A negative-NPV project can still be worth paying for, as a licence, lease or option on land. That is the logic behind buying acreage or a permitted site to hold. Synthesis

Staged investment: compound options

Many energy developments come in phases: geology, exploration drilling, appraisal, then development. Each phase buys the right to start the next, so each phase is an option on an option. Finnerty models a North Sea field as three such call options (test drilling, appraisal, production) plus an abandonment option during production, solved by working backward from the production decision. Finnerty ch.12 (pp.217–220) Copeland and Antikarov value sequential compound options on a lattice. Value the later option first, then use its values as the payoff of the earlier one. Copeland & Antikarov ch.6 (pp.164–168)

Worked example 4 · appraise, then developChecked by code

A field would be worth $200 if developed. Appraisal costs $20 in one year, and if done, development costs $220 in three years. Volatility 35%, r = 5%, payout 4%.

commit to both stages now: NPV = $−31.00 right to develop in year 3 (if appraisal were free): $37.97; staged value with the $20 appraisal decision in year 1: $23.14

Staging turns a −$31m commitment into an opportunity worth $23m, because appraisal is only paid for in states where development still looks valuable. This is why upstream companies spend on information before capital. Finnerty ch.12 (pp.215–217) Synthesis

ALM analogy

A lattice for project value is the binomial interest-rate tree you would use for callable bonds or prepayable mortgages. Abandonment is a put the issuer holds, expansion a call, and their interaction is like a bond with both call and put features, where the options can't be valued separately and added. Staged development is a sequence of commitments, like a pipeline of new business where each stage of underwriting buys information before capital is committed. Synthesis

Dated: regimes and fiscal terms

Finnerty's field example (2013) uses a specific North Sea fiscal structure (royalty, state participation, carried interest, tax). Fiscal regimes and decommissioning obligations change often, and the UK's Energy Profits Levy, introduced in 2022, is one recent example. Always rebuild the after-tax payoff from current terms before valuing the options. Outside the texts

Going deeper: payouts make early exercise rational

For a call on an asset that pays nothing, waiting is always at least as good as exercising early. For a project, waiting means giving up its cash flows, the payout rate \(\delta\). The higher \(\delta\), the more costly delay becomes, and the lower the value that triggers investment. That is why the deferral option in Example 3 includes an early-exercise region. With δ = 0 the lattice would never invest before the end of the window. The same logic gives the investment trigger in Module 3, where \(\delta\) enters through \(\beta\). Dixit & Pindyck ch.5 §4 Synthesis

Key takeaways

  • Build a recombining tree for project value with payouts, and check it against a closed-form case.
  • Abandonment, expansion, contraction and deferral are American options valued by backward induction.
  • Options on one project interact and don't add. Value them together.
  • Staged projects are compound options. Paying for information first can turn a negative NPV into positive value.
